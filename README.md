## 新加坡云服务器价格为什么差这么多

三档价格的成本结构完全不同，拆开看就明白了。

带宽是最贵的一项。人民币百元以内的机器端口大多在 1–30Mbps，个别只给 5Mbps；大厂境外轻量把 30M 峰值带宽和固定流量包打包卖；面向大陆优化的中高端产品直接 1Gbps 起步。机房按 Gbps 核算带宽成本，5Mbps 和 1Gbps 之间的差距不是配置单上几个数字能体现的。

流量配额跟着带宽走，写法还不一样。有写“不限流量”、但端口只有 5Mbps 的，跑满一个月理论上也就 1.6TB 上下；有给 1TB 流量配 30M 端口的；还有把配额写死的，比如 500GB、1TB、2TB、5TB、10TB，超了就限速。

回程线路最容易被低估，也最难从价格标签上看出来。去程大部分机房都正常，真正决定晚高峰体验的是回程走什么。电信 CN2 GIA、联通 AS9929、移动 CMIN2 三条都优化，和只优化其中一条，成本差得不少。有些机器白天 ping 好看，晚上八点以后开始抖，原因多半在这里。

## 新加坡到国内到底多少毫秒

官网首页写的是“RTT < 50ms across mainland China”，官方文档的节点表写新加坡 < 70ms，两处口径不一样。第三方实测（2026-10-01，SIN.Pulse.Nano）给了更细的答案：

- **广东**：电信 46.75ms、联通 38.82ms、移动 49.29ms
- **上海**：电信 67.86ms、联通 63.15ms、移动 70.41ms
- **北京**：电信 81.27ms、联通 75.62ms、移动 90.21ms

路由层面，电信走 CTG GIA / CN2 GIA，联通走 9929，移动走 CMIN2，三网各自优化。华南用户体验接近宣传值，北方用户按 70–90ms 做预期更实际。这是一台 Nano 的一次测试结果，不代表所有套餐、所有城市、所有时段。

## 600Gbps 防护不是默认送的

首页大字写“up to 600 Gbps mitigation capacity”，很容易被理解成标配。官方文档说得更清楚：所有实例默认是 best-effort 基础清洗，免费；600 Gbps 高级清洗是付费附加项，需要联系支持或查看网站。

基础防护的边界也写在文档里：当攻击影响到同网段其他客户时，系统会对实例 IP 执行黑洞 30–60 分钟，自动解除，无法人工干预，这期间所有进出流量被丢弃。因 DDoS 被黑洞的实例不在退款范围内。

官方没有公开高级清洗的加购价格，只说需要联系支持。需要把高防写进预算的项目，得先询价才能算出真实总成本——月费 $49 和月费 $49 + 高防加购，是两笔完全不同的账。真要扛攻击的业务，这部分成本要单独列，别在对比月费时漏掉。

- **到期规则**：逾期 5 天终止，数据可能无法恢复，重要数据提前备份

退款那条值得单独提一句：24 小时窗口刚好够跑一轮晚高峰测速，但这期间别往里放重要数据。
